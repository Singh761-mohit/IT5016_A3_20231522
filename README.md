REQUISTION SYSTEM - PYTHON PROJECT
==================================

## ABOUT THIS PROJECT:
-----------------------
- A simple requisition system made in Python.
- Helps staff request materials/items.
- Approves requests if the total price is below a set limit.

## WHAT IT DOES:
----------------
1. Collects staff information (date, ID, name).
2. Creates a unique requisition ID.
3. Asks how many items are needed.
4. Takes name and price of each item.
5. Calculates total cost.
6. Approves request if total is less than 500.
7. Shows a full summary of the request.

## HOW TO RUN:
--------------
1. Make sure Python is installed.
2. Copy the code into a file named `requisition_system.py`.
3. Open terminal or command prompt.
4. Run the file: 
   `python requisition_system.py`
5. Follow the prompts.
